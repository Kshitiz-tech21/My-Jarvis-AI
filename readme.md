# My Personal J.A.R.V.I.S. Implementation

A customized deployment of the Mark-LIII AI Assistant using Gemini Multimodal Live API.

## Features
- Real-time Voice Interaction
- System Monitoring
- Vision Capabilities (Screen/Camera)
- Long-term Memory

## How to Launch
Run the `Launch_Jarvis.bat` file located on the desktop.
